# Конвенции проекта

## Язык
Спеки, документация и **комментарии в коде — по-русски**. Существующие английские
комментарии переводим по мере правки файлов, не отдельной задачей.

## Изменения только через change
Код меняется только в рамках папки `openspec/changes/<дата>-<имя>/`. Исключение — опечатка
в тексте или правка без изменения поведения; такое коммитится с пометкой «без change».

## Правила кода
ES-модули, стрелки, без точек с запятой, отступ 2 пробела. Имена файлов — по назначению.
Ноль npm-зависимостей в рантайме; dev-скрипты тоже пишем на голом Node.

## Тесты
`node --test --test-force-exit`, файлы в `test/`. Даты в тестах только вычисляемые от `Date.now()`.
**Перед деплоем — полный локальный прогон.** Деплой через `deploy-safe` (сам откатит при провале).

## Коммиты
Одна задача — один осмысленный коммит, по-русски, с причиной изменения. Ветки: `chat-bot`,
`app-translation`; `main` держим равным текущему состоянию.

## Определение готовности (DoD)
1. дельта-спека соответствует коду;
2. тесты добавлены и зелены локально и на сервере;
3. задеплоено через `deploy-safe`;
4. `docs/HANDOFF.md` обновлён;
5. изменение заархивировано (`changes/archive/<дата>-<имя>/`), спеки влиты.

## Секреты
Открытым текстом в репозитории не лежит ничего. Значения — в `secrets/prod.env.enc`
(шифртекст), расшифровка: `node tg-agent/tools/secrets.mjs decrypt` (пароль — вне репозитория).
`.env` в `.gitignore`. Новый ключ — строка в `secrets/keys.md` и перешифровка.

## Запреты
Не трогать xray/VPN на Испании. Не перезагружать серверы без явного разрешения владельца.
Не менять `tg-agent/src/bot.mjs` без локального прогона тестов.

## Валидация структуры
`node tg-agent/tools/spec-check.mjs` — проверяет папки изменений, дельты и требования.
