# Спека домена integrations

Все внешние подключения живут в `src/integrations/`: единый контракт таймаутов и ошибок, ключи только из конфига, ядро и домены сеть не вызывают.

## ADDED Requirements

### Requirement: Внешние подключения изолированы
Код, который ходит в сеть (мессенджеры, модель, речь, погода, YouTube, умный дом, поиск),
ДОЛЖЕН находиться в `src/integrations/`. Ядро и домены сеть не вызывают.

#### Scenario: Смена провайдера
- GIVEN нужно заменить провайдера речи
- WHEN меняется реализация
- THEN правки ограничены `src/integrations/`
- AND ядро и домены не меняются

#### Scenario: Проверка изоляции
- GIVEN разработчик ищет сетевые вызовы по проекту
- WHEN он ищет `fetch(` вне `src/integrations/`
- THEN находит только явно разрешённые места, отмеченные в спеке

### Requirement: Ошибки и таймауты провайдеров единообразны
Каждое подключение ДОЛЖНО иметь таймаут и возвращать ошибку с понятным текстом, не
роняя обработку сообщения.

#### Scenario: Провайдер не ответил
- GIVEN провайдер не отвечает дольше таймаута
- WHEN подключение вызывается
- THEN операция завершается понятной ошибкой
- AND бот продолжает отвечать на другие сообщения

### Requirement: Секреты только из конфига
Подключения ДОЛЖНЫ получать ключи и адреса через конфиг, а не читать `.env` или
переменные окружения самостоятельно.

#### Scenario: Запуск с конфигом извне
- GIVEN тест передаёт подключению свой конфиг
- WHEN подключение делает запрос
- THEN используется переданный ключ и адрес
- AND файлы `.env` не читаются

## MODIFIED Requirements

### Requirement: Порт платформы сохраняется
Контракт платформы (`src/platforms/port.mjs`) остаётся прежним; адаптеры переезжают в
`src/integrations/`, старые пути — тонкие реэкспорты.

#### Scenario: Старый импорт продолжает работать
- GIVEN код импортирует адаптер по прежнему пути
- WHEN изменение задеплоено
- THEN импорт работает через реэкспорт
- AND поведение не меняется

## ADDED Requirements

### Requirement: Клиент агента v2
Интеграция с агентом ДОЛЖНА уметь `/v1/tasks`, ответ на вопрос, отмену, ревизию и файлы
`/v1/files`, сохраняя прежний `/bridge` как совместимый режим. Сетевые вызовы остаются
только в `integrations`, таймауты и ошибки единые.

#### Scenario: Задача с файлом
- GIVEN нужно передать агенту файл
- WHEN клиент отправляет задачу
- THEN файл загружается через `/v1/files`
- AND в задаче остаётся только `fileId`

#### Scenario: Ошибка агента
- GIVEN агент ответил `5xx` или не ответил
- WHEN клиент возвращает результат
- THEN ошибка понятна, таймаут соблюдён
- AND бот продолжает отвечать на другие сообщения

### Requirement: Получатель событий v2
HTTP-приёмник событий ДОЛЖЕН принимать событие v2 с `eventId`, проверять токен и маршрут,
дедуплицировать, доставлять пользовательские события и отвечать подтверждением обработки.

#### Scenario: Подтверждение
- GIVEN событие доставлено
- WHEN приёмник отвечает
- THEN ответ содержит `ok`, `eventId`, `processed: true`
- AND повтор события не создаёт сообщение

#### Scenario: Старый текстовый режим
- GIVEN пришло тело `{text, title}` без `eventId`
- WHEN приёмник его обрабатывает
- THEN доставка идёт как раньше
- AND формат ответа совместим со старым агентом

## ADDED Requirements

### Requirement: VK умеет отправлять файлы
Адаптер VK ДОЛЖЕН реализовать `sendDocument`: загрузить файл в сообщения беседы и отправить
его документом с подписью.

#### Scenario: PDF в беседу VK
- GIVEN владелец просит файл в VK
- WHEN файл собран инструментом `file` или `/export`
- THEN в беседу приходит документ с правильным именем
- AND подпись к файлу сохраняется

#### Scenario: Документ в личку VK
- GIVEN файл отправляется в личный чат VK
- WHEN загрузка прошла
- THEN файл приходит так же, как в беседу
- AND размер и тип определяются по содержимому

### Requirement: Ошибка загрузки объясняется
Если VK не принял документ, пользователь ДОЛЖЕН получить понятный текст причины, а не тишину.

#### Scenario: VK отклонил загрузку
- GIVEN VK возвращает ошибку загрузки
- WHEN бот пытается отправить файл
- THEN приходит текст с причиной
- AND сессия бота не падает

### Requirement: Возможности соответствуют платформе
Список возможностей и подсказки ДОЛЖНЫ отражать, что VK теперь умеет файлы.

#### Scenario: «Что ты умеешь» в VK
- GIVEN владелец спрашивает возможности в VK
- WHEN бот отвечает
- THEN файлы на выход упомянуты как доступные
- AND голосовые ответы по-прежнему честно отсутствуют

- THEN приходит текстовый ответ
- AND пользователь видит причину в журнале, а не тишину

### Requirement: Возможности отражают озвучку в VK
Подсказка возможностей ДОЛЖНА говорить, что в VK доступны голосовые ответы.

#### Scenario: «Что ты умеешь» в VK

- WHEN бот отвечает
- THEN голосовые ответы упомянуты как доступные
