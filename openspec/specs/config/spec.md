# Спека домена config

## ADDED Requirements

### Requirement: Настройки контракта с агентом
Домен `config` ДОЛЖЕН читать и валидировать настройки контракта v2 с умолчаниями,
не ломая старый env:

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `AGENT_CONTRACT` | `v2` | режим связи: `v2` или прежний `v1` |
| `AGENT_FILES_MAX_BYTES` | `20971520` | предел файла при загрузке/скачивании |
| `AGENT_EVENTS_RETENTION_DAYS` | `30` | срок хранения журнала `eventId` |
| `AGENT_ANSWER_TIMEOUT_MS` | `86400000` | сколько ждать ответа на вопрос агента |

#### Scenario: Старый env
- GIVEN новых ключей нет
- WHEN сервис запускается
- THEN используются значения по умолчанию
- AND прежние `AGENT_BRIDGE_URL`, `AGENT_BRIDGE_TOKEN`, `OUTBOX_TOKEN` не меняют смысл

#### Scenario: Неверное значение
- GIVEN `AGENT_CONTRACT=foo`
- WHEN сервис запускается
- THEN старт прерывается ошибкой с именем переменной
- AND значение секретов в сообщении не раскрывается
