# Дельта для домена agent-link

## ADDED Requirements

### Requirement: Контракт v2 передаёт проверенный principal
Постановка задачи через v2 ДОЛЖНА передавать `principal.userId` и `scopeId` из
проверенного контекста пользователя, отдельно от маршрута доставки.

#### Scenario: Задача второго пользователя
- GIVEN второй разрешённый пользователь поручает задачу
- WHEN бот вызывает `/v1/tasks`
- THEN `route` указывает место доставки
- AND `principal.userId` указывает автора
- AND значение не выводится из текста задачи.
