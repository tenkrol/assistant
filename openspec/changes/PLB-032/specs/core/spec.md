# Дельта для домена core

## ADDED Requirements

### Requirement: Интервальный повтор начинается с пяти минут
Система ДОЛЖНА принимать `every:N` для значений от 5 до 1440 минут с шагом 5.

#### Scenario: Повтор каждые пять минут
- GIVEN пользователь создаёт напоминание с повтором `every:5`
- WHEN значение проверяется и вычисляется следующий срок
- THEN значение принимается
- AND следующий срок наступает через пять минут.
