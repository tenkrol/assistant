# Дельта для домена miniapp

## ADDED Requirements

### Requirement: Медиа изолированы по владельцу
Miniapp ДОЛЖНО отдавать и принимать в сообщение медиа только того пользователя,
который создал файл.

#### Scenario: Чужой идентификатор медиа
- GIVEN два разрешённых пользователя и файл первого пользователя
- WHEN второй пользователь запрашивает файл или прикрепляет его к сообщению
- THEN сервер отвечает как для отсутствующего файла
- AND байты не передаются.

### Requirement: Задачи агента изолированы по principal
Статус, детали и отмена задач агента ДОЛЖНЫ быть доступны только владельцу задачи.

#### Scenario: Второй пользователь открывает раздел агента
- GIVEN у первого пользователя есть задача
- WHEN второй пользователь читает статус, детали или вызывает отмену
- THEN задача отсутствует в списке
- AND детали и отмена отвечают 404
- AND агент не получает отмену.

### Requirement: Telegram initData работает для бинарных данных
После валидной Telegram initData miniapp ДОЛЖНО загружать и открывать медиа и
артефакты без парольного входа.

#### Scenario: WebApp без парольной cookie
- GIVEN запрос `/api/auth/session` подписан initData
- WHEN пользователь загружает или открывает файл
- THEN браузер передаёт действующую аутентификацию
- AND сервер не отвечает 401.
