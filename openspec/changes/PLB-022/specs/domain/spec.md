# Дельта для домена domain

## ADDED Requirements

### Requirement: Память проверяет права на каждую операцию
`list`, `select`, `export`, `history`, `remember`, `correct`, `forget`, `undo` ДОЛЖНЫ проверять
права через `canRead`/`canWrite` в общем сервисе памяти; проверка в отдельных командах
недостаточна. Viewer не пишет, отозванный участник не читает.

#### Scenario: Viewer пытается записать факт
- GIVEN пользователь имеет роль viewer в проекте
- WHEN `memory.remember` вызывается для факта этого проекта
- THEN запись отклоняется с понятным текстом
- AND данные проекта не меняются

#### Scenario: Отозванный участник читает
- GIVEN у пользователя отозван доступ к проекту
- WHEN он вызывает `memory.list` или `memory.select`
- THEN факты проекта не попадают в результат
- AND личные факты остаются видимы

### Requirement: Дедупликация и замена только внутри области
Поиск дубля и заменяемого факта ДОЛЖЕН ограничиваться той же областью (`scopeId`) и субъектом;
`supersedesId` не может связывать записи разных областей. Перенос факта между областями —
отдельная операция, а не `correct`.

#### Scenario: Запись в проекте не трогает личное
- GIVEN в личной области активен факт «живу в Москве»
- WHEN в проекте сохраняется «живу в Казани»
- THEN оба факта активны в своих областях
- AND личный факт не помечается заменённым

#### Scenario: Исправление внутри проекта
- GIVEN в проекте активен факт «живу в Казани»
- WHEN в том же проекте сохраняется «живу в Уфе»
- THEN старый факт помечается заменённым новым
- AND личная область не затрагивается
