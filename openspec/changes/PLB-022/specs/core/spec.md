# Дельта для домена core

## ADDED Requirements

### Requirement: Задачи проходят ACL до кандидатов и доставки
Кандидаты типа «поручение» ДОЛЖНЫ нормализоваться к проверенному principal и области и проходить
`canRead` до формирования кандидатов, обзора и журнала решений, а также непосредственно перед
отправкой. Задача без известного владельца не считается общедоступной.

#### Scenario: Чужая личная задача
- GIVEN target пользователя 1, задача принадлежит пользователю 2, доступа нет
- WHEN тик проактивности обрабатывает задачи
- THEN карточка чужой задачи не попадает ни в кандидаты, ни в обзор, ни в отправку
- AND в журнале решений отмечено, что задача отфильтрована по доступу

#### Scenario: Общая задача проекта
- GIVEN задача принадлежит общему проекту, пользователь — его участник
- WHEN тик обрабатывает задачи
- THEN карточка доставляется участнику
- AND после отзыва доступа не доставляется
