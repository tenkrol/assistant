# PLB-027: авто-распознавание заявки на доработку

Основание: E4/E11 — бот должен отличать запрос на изменение продукта от обычной
задачи, а не только по явной команде `/request`.

## Что меняется
- Детектор `looksLikeChangeRequest(text)`: глагол изменения + продуктовая область.
- В обычном сообщении владельца, если детектор сработал и мост доступен, создаётся
  draft-заявка (тот же `/v1/requests`), бот отвечает requestId/компонентами/вопросом.
- Явные задачи и вопросы не перехватываются; при ошибке — обычный путь.

## Не входит
LLM-классификатор; PR через API.
