# Решение

`classifyChangeRequest(text)`:
1. нет глагола изменения → data;
2. явная продуктовая конструкция (`в боте`, `бот должен`, `добавь возможность`,
   `научи`, `сделай так чтобы бот`) → product;
3. иначе есть пользовательские данные (напоминание/календарь/память/поручение) → data;
4. иначе есть продуктовая лексика → ambiguous;
5. иначе data.

Conversation: `product` → createRequest; `ambiguous` → вопрос без создания;
`data` → обычный путь. Блок стоит после `agentLink.handleOwnerMessage`.
