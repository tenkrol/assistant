# Техническое решение

## Как устроено сейчас
`src/domain/repeats.mjs` знает daily/weekly/weekdays/monthly/`every` (15/30/60/120 минут) для
мини-приложения; `reminders.mjs` умеет `repeat` и `advance`. Вечернего чек-ина нет. Тон — общий
`/mood`/`/character`.

## Предлагаемое решение
1. Расширить `repeat` до `every:<минуты>` с валидацией и минимальным порогом (15 минут),
   `advance` переносит `dueAt` вперёд от исходного, идемпотентно по `dueAt`.
2. `settings.eveningCheckIn: { enabled, at, tone }` в профиле пользователя; отдельный
   кандидат для существующего планировщика (не новый таймер), подавление, если пользователь
   писал в последние 2 часа.
3. `tone: 'gentle'|'neutral'|'strict'` у напоминания; `domain/reminders.mjs` формирует
   префикс/суффикс текста, время и кнопки не меняются.
4. Команды: «каждые N часов», «спрашивай вечером», «ласково/строго» — через существующий
   инструмент `remind` и маршрутизатор; настройки чек-ина — `/proactive`-подобная команда.

## Влияние
Риск: спам интервальными напоминаниями. Поэтому минимальный интервал 15 минут, лимит активных
напоминаний сохраняется, тон не влияет на частоту. Откат — `deploy-safe`.

## Альтернативы
Отдельный планировщик для чек-ина — запрещено конвенцией (один таймер).
