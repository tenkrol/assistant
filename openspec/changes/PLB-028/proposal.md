# PLB-028: F1 — не путать поручения с заявками на разработку

Основание: review F1. Детектор считал «Добавь напоминание…» заявкой и перехватывал
обычное действие.

## Что меняется
- Классификатор намерения: `data` (напоминания/календарь/память/поручения),
  `product` (изменение поведения бота/агента), `ambiguous`.
- Авто-заявка только для product; ambiguous — уточняющий вопрос; data идёт обычным путём.
- Авто-заявка проверяется после ответа агента на открытый вопрос, чтобы не перехватывать
  продолжение диалога.
- `/request` остаётся явным входом.

## Не входит
LLM-классификатор и новые разрешения.
