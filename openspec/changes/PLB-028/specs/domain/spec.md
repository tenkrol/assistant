# Дельта для домена domain

## ADDED Requirements

### Requirement: Интервальные напоминания
Напоминание ДОЛЖНО поддерживать повтор «каждые N» (минуты и часы), срабатывать через N и
переноситься вперёд без дублей после рестарта.

#### Scenario: Вода каждые два часа
- GIVEN пользователь просит «напоминай пить воду каждые 2 часа»
- WHEN наступает время первого срабатывания
- THEN приходит напоминание
- AND следующее наступает ровно через 2 часа, без дублей при перезапуске

#### Scenario: Ограничение интервала
- GIVEN пользователь просит интервал меньше минимального
- WHEN напоминание создаётся
- THEN бот объясняет минимальный интервал
- AND напоминание не создаётся молча с другим значением

### Requirement: Вечерний чек-ин
Пользователь ДОЛЖЕН включать вечерний вопрос («как прошёл день») с указанием времени и тона;
вопрос приходит один раз в день и не приходит, если пользователь сам уже писал в это время.

#### Scenario: Включение
- GIVEN пользователь просит «спрашивай вечером, как прошёл день в 21:00»
- WHEN наступает 21:00
- THEN приходит один вопрос
- AND повторно в тот же день не приходит

#### Scenario: Уже говорили
- GIVEN пользователь писал боту в 20:55
- WHEN наступает время чек-ина
- THEN вопрос не приходит в тот же день
- AND следующий — на следующий день

### Requirement: Тон напоминания
Напоминание ДОЛЖНО принимать тон (ласково / нейтрально / строго), который меняет только текст
доставки, но не время, повтор и кнопки.

#### Scenario: Ласковое напоминание
- GIVEN пользователь просит «напомни ласково завтра в 9 выпить таблетки»
- WHEN напоминание срабатывает
- THEN текст мягкий и обращён к человеку
- AND время и кнопки такие же, как у обычного напоминания

#### Scenario: Персональность тона
- GIVEN у двух людей разные тона
- WHEN обоим приходит напоминание
- THEN каждый получает свой тон
- AND настройки друг друга не меняются
