# Дельта для домена miniapp

## ADDED Requirements

### Requirement: Строки интерфейса живут в словарях
Все видимые подписи панели ДОЛЖНЫ храниться в `public/locales/<язык>.json`; в разметке
русских строк быть не должно.

#### Scenario: Английский язык
- GIVEN панель открыта с английским языком
- WHEN отрисовываются вкладки и кнопки
- THEN все подписи на английском
- AND в разметке не осталось русского текста

#### Scenario: Расхождение словарей
- GIVEN в одном словаре есть ключ, которого нет в другом
- WHEN запускаются тесты
- THEN тест падает и называет ключ
- AND деплой не проходит

### Requirement: Язык выбирается и сохраняется
Панель ДОЛЖНА брать язык из `Telegram.WebApp.CloudStorage` (у каждого пользователя свой),
при отсутствии — из `initData.language_code`, иначе русский.

#### Scenario: Первый запуск
- GIVEN пользователь открыл панель впервые, язык Telegram — английский
- WHEN панель загрузилась
- THEN интерфейс на английском
- AND выбор сохраняется в CloudStorage

### Requirement: Русская версия не меняется
Русский интерфейс ДОЛЖЕН остаться визуально идентичным текущему.

#### Scenario: Сравнение с прежним видом
- GIVEN панель открыта на русском
- WHEN сравниваем с прежней версией
- THEN тексты и порядок вкладок совпадают
- AND существующие тесты мини-приложения зелёные

### Requirement: Ошибки API переводятся
Сообщения об ошибках мини-приложения ДОЛЖНЫ иметь код, а клиент — переводить его по словарю.

#### Scenario: Нет доступа
- GIVEN подпись initData неверна
- WHEN API отвечает 401
- THEN панель показывает переведённый текст ошибки
- AND не показывает код или английский стек
