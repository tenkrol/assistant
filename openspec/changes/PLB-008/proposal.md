# PLB-008 — перевод мини-приложения на английский

## Зачем
Панель внутри Telegram (`/app`) только на русском. Владелец просит английский и основу для
других языков, не меняя русскую версию ни на пиксель.

## Что меняется
Домен `miniapp`: строки выносятся в словари `public/locales/<язык>.json`, появляется выбор
языка (по умолчанию — язык Telegram, иначе русский), ошибки API переводятся по словарю.

## Чего не делаем
Не переводим данные пользователя (названия напоминаний, события, память) и не меняем вид панели.

## Как проверяем
Русская версия идентична прежней; английская переключается, сохраняется и не теряет строк;
тест сравнивает наборы ключей словарей; задеплоено и проверено в Telegram.
