# PLB-018 — проекты и общие пространства (BP-03)

## Зачем
Сейчас изоляция данных есть только по человеку (`chatId`/`userId`): второй пользователь не
видит чужое, но нет способа вести общие дела семьи (проект «дача», «ремонт») и явно выдавать
доступ. Пакет спек 18.10 ставит BP-03 следующим шагом после поручений и прогресса.

## Что меняется
Домен `core`: появляется понятие пространства (`scope_id`) с участниками и правами; личные
данные принадлежат пространству человека, общие — явно созданному. Все чтения и записи данных
проверяют членство. Дельта перенесена дословно из BP-03.

## Чего не делаем
Не переписываем хранилища и не меняем формат личных данных; не трогаем работу параллельной
сессии (`agent-bridge/v2.mjs`, `PLB-017`).

## Как проверяем
Второй человек не видит чужое ни в списке, ни по известному id; участник общего пространства
видит общее; сценарий AC-06 в каталоге приёмки остаётся зелёным.
