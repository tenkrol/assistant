# Дельта для домена storage

## ADDED Requirements

### Requirement: Запись атомарна
Слой хранения ДОЛЖЕН писать файл через временный файл и переименование, чтобы сбой в
процессе записи не оставлял пустой или частичный файл.

#### Scenario: Падение во время записи
- GIVEN хранилище сохраняет состояние
- WHEN процесс прерывается между записью временного файла и переименованием
- THEN на диске остаётся предыдущая валидная версия файла
- AND временный файл не мешает следующему запуску

#### Scenario: Полный диск
- GIVEN на диске не хватает места
- WHEN хранилище пытается сохранить состояние
- THEN запись завершается ошибкой с понятным сообщением
- AND существующий файл остаётся валидным и читаемым

### Requirement: Один писатель на файл
Слой хранения ДОЛЖЕН исключать одновременную запись одного файла из двух процессов.

#### Scenario: Две копии бота
- GIVEN запущены два процесса, которые пишут в одно хранилище
- WHEN оба пытаются сохранить состояние
- THEN записи не перемешиваются
- AND второй процесс получает отказ или ждёт, а не портит файл

### Requirement: Версия схемы и миграции
Каждый файл состояния ДОЛЖЕН содержать версию схемы. При чтении старой версии слой
хранения ДОЛЖЕН мигрировать данные и сохранить копию исходного файла.

#### Scenario: Старый файл без версии
- GIVEN на диске файл состояния, записанный прошлой версией бота
- WHEN бот запускается
- THEN данные читаются и приводятся к новой схеме
- AND рядом остаётся резервная копия исходного файла

#### Scenario: Неизвестная будущая версия
- GIVEN файл содержит версию схемы новее, чем понимает код
- WHEN бот запускается
- THEN он не перезаписывает файл
- AND сообщает об ошибке понятным текстом

### Requirement: Битый файл не теряется
Если файл не читается как JSON, слой хранения ДОЛЖЕН отложить его копию и продолжить
работу с пустым состоянием, а не падать и не затирать данные.

#### Scenario: Повреждённый JSON
- GIVEN файл состояния повреждён
- WHEN хранилище загружается
- THEN повреждённый файл копируется в отдельный файл с датой
- AND бот стартует с пустым состоянием и пишет об этом в журнал
