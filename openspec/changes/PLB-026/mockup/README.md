# Макет мобильного пульта ассистента (PLB-026)

Сайт для телефона, через который можно говорить с ботом и управлять им: чат, планы,
память, длинные задачи агента, файлы и настройки. Пять разделов в нижней навигации вместо
шпаргалки команд.

Это **макет**, а не рабочее приложение: данные демонстрационные, сети и сервера нет.
Задача — согласовать состав экранов и вид до написания production-кода.

Превью всех экранов — [`preview.jpg`](preview.jpg); интерактивный борд — `board.html`.

## Как открыть

1. **Дизайн-борд** — `board.html` (на компьютере): все 13 экранов в рамках телефона,
   принципы, дизайн-токены и таблица «экран → API». Начните с него.
2. **Интерактив** — `index.html`: тот же интерфейс на весь экран. На телефоне откройте
   файл в браузере; на компьютере он показывается в рамке телефона.

Всё открывается двойным щелчком, без сервера и сборки. Внешних файлов и зависимостей нет:
только `index.html`, `app.css`, `app.js`.

## Что можно потрогать

| Сценарий | Что сделать |
|---|---|
| Чат | Написать боту, нажать быстрый чип, отправить голосовое (микрофон) |
| Планы | Переключить «Напоминания / Календарь», нажать «+», создать напоминание |
| Календарь | Выбрать день, полистать месяцы, увидеть точки напоминаний и событий |
| Память | Добавить факт в строку снизу, найти через поиск, удалить через «⋯» |
| Агент | Отправить задачу — прогресс пойдёт сам, результат уедет в «Завершены» |
| Файлы | Отфильтровать по формату, поискать по имени, нажать на файл |
| Ещё / Настройки | Сменить характер, режим, модель, тему, крупный текст, язык |
| Вход | Нажать «Войти через Telegram» или ввести любой код (демо) |

Подэкраны («Файлы», «Настройки», «Статистика») открываются из «Ещё»; возврат — стрелкой
или системной кнопкой «назад» (история браузера).

## Экраны

1. **Вход** — Telegram или одноразовый код из бота.
2. **Чат** — диалог, утренний дайджест, карточка созданного напоминания, быстрые действия,
   вложения, голосовой ввод, постепенный ответ.
3. **Планы** — напоминания и события: сегодня / завтра / позже, повтор, отметка выполнения.
4. **Календарь** — месяц с точками, выбранный день, ближайшие события.
5. **Новое напоминание** — шторка: текст, быстрые даты, повтор, тихие часы.
6. **Память** — город, факты с источником, добавление и удаление.
7. **Агент** — новая задача, прогресс и шаги, завершённые задачи.
8. **Файлы** — формат, размер, дата, фильтры, поиск, экспорт.
9. **Ещё** — профиль, плитки, состояние серверов, приглашения.
10. **Настройки** — характер, режим, модель, озвучка, дайджест, тихие часы, тема, язык, доступ.
11. **Статистика** — токены за сегодня и неделю, лимит, нагрузка серверов.
12. **Светлая тема** — чат и планы (проверка контраста и токенов).

## Что демонстрационное

- Все данные зашиты в `app.js`; сеть не используется.
- Скачивание файлов, экспорт, копирование кода приглашения — тосты-заглушки.
- Английский язык выбирается, но строки пока русские: перенос в словари — этап реализации.
- «Проекты» и «Сеансы» показывают состав, но не меняют данные.
- Строка состояния (9:41, батарея) нарисована для макета; на телефоне её заменит системная.

## Что за макетом

| Экран | Данные | Статус |
|---|---|---|
| Планы | `/api/reminders`, `/api/events` | API уже есть в `src/miniapp.mjs` |
| Память | `/api/memory` | API уже есть |
| Статистика | `/api/state` | API уже есть |
| Вход | `initData` / Login Widget / код из бота | расширить |
| Чат | `GET/POST /api/chat` | новый API |
| Агент | `GET/POST /api/agent/tasks` | новый API |
| Файлы | `GET /api/files`, `GET /api/files/:id` | новый API |
| Настройки | `GET/PATCH /api/settings` | новый API |
| Установка | PWA-манифест + service worker | новое |

## Устройство файлов

```
mockup/
  index.html   — разметка всех экранов и инлайн-спрайт иконок
  app.css      — токены, тёмная/светлая темы, компоненты, адаптив
  app.js       — навигация, демо-данные, шторки, сценарии
  board.html   — дизайн-борд для показа и согласования
  preview.jpg  — превью всех 13 экранов одним листом
  README.md    — этот файл
```

Параметры URL для борда и проверки:

- `index.html?screen=chat` — сразу нужный экран (`auth`, `plans`, `memory`, `agent`,
  `files`, `more`, `settings`, `stats`);
- `&view=calendar` — «Планы» в виде календаря;
- `&sheet=reminder|event|fact|invite|help|logout` — открыть шторку поверх экрана;
- `&theme=light` — светлая тема.

## Стиль

- Палитра Telegram: фон `#101923`, карточка `#182431`, акцент `#2ea6ff`.
- Системные шрифты, без внешних ресурсов; инлайн-SVG вместо иконочных шрифтов.
- Радиусы: 22/16/12/999; отступы 4/8/12/16/20/24.
- Область нажатия — не меньше 44×44 px; safe-area снизу; поддержка
  `prefers-reduced-motion`; тёмная и светлая темы.
- Основные действия — в нижней трети: навигация, отправка, создание.
