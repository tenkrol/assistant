# Дельта для домена integrations

## ADDED Requirements

### Requirement: Мост отдаёт владельца и область задачи
`/v1/activity` агента ДОЛЖЕН возвращать для каждой задачи проверенного владельца (`userId`) и
область (`scopeId`); без них задача не становится общедоступной.

#### Scenario: Задача с владельцем
- GIVEN агент выполнил задачу пользователя 433296567
- WHEN бот запрашивает активность
- THEN в записи есть userId и scopeId
- AND уведомление доставлено только владельцу

#### Scenario: Задача без владельца
- GIVEN в активности запись без userId
- WHEN проактивность обрабатывает её
- THEN она отфильтрована и записана в журнал
- AND никому не доставлена
