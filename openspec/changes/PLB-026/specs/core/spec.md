# Дельта для домена core

## ADDED Requirements

### Requirement: Бот поднимается сам и это проверяется
Бот ДОЛЖЕН автоматически перезапускаться при падении, а деплой — считаться успешным только
после подтверждённого старта. Внешний сторож ДОЛЖЕН замечать недоступность и сообщать.

#### Scenario: Падение бота
- GIVEN процесс бота упал
- WHEN systemd перезапускает его
- THEN бот снова отвечает в течение минуты
- AND в журнале отмечен факт перезапуска

#### Scenario: Деплой без зелёного старта
- GIVEN деплой завершил тесты, но бот не поднялся
- WHEN проверяется результат
- THEN деплой считается проваленным и откатывается
- AND в чат владельцу приходит сообщение о проблеме

#### Scenario: Внешний сторож
- GIVEN бот недоступен дольше порога
- WHEN сторож проверяет состояние
- THEN владелец получает уведомление
- AND повторных алертов не больше одного в час

### Requirement: Просроченное доставляется с честной пометкой
Просроченное напоминание (из-за простоя) НЕ ДОЛЖНО молча удаляться: оно доставляется с
пометкой «пропущено, было на …», если просрочено не больше окна догона; старше — снимается
и учитывается в счётчике.

#### Scenario: Бот был выключен в момент напоминания
- GIVEN напоминание на 09:00, бот поднялся в 18:38
- WHEN выполняется догон
- THEN приходит сообщение «пропущено, было на 09:00»
- AND такое не повторяется по кругу

### Requirement: Обзор по всем чатам пользователя
Обзор ДОЛЖЕН собирать кандидатов из всех чатов, где у пользователя есть данные и доступ,
включая беседы, с учётом областей и ролей.

#### Scenario: Напоминание в беседе
- GIVEN погодное напоминание создано в беседе, пользователь — участник
- WHEN наступает время обзора
- THEN пункт из беседы попадает в обзор этого пользователя
- AND чужие беседы не попадают
