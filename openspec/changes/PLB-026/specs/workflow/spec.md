# Дельта для домена workflow

## ADDED Requirements

### Requirement: Деплой проверяет бота после старта
`deploy-safe` ДОЛЖЕН после переключения релиза ждать подтверждения, что процессы поднялись и
отвечают; иначе — откат и уведомление.

#### Scenario: Релиз не поднялся
- GIVEN новый релиз переключён, но процесс не активен
- WHEN истекает окно проверки
- THEN выполняется откат на предыдущий релиз
- AND владелец получает сообщение с причиной
