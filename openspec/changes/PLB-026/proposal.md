# PLB-026 — доступность бота, догон просроченного, обзор по всем чатам, идентичность задач

## Зачем
Разбор 19.10 показал три реальные причины «проактивность плохо работает»:
1. Бот был недоступен ~22 часа (с 18.10 20:47 до 19.10 18:38) — в 09:00 по Москве его просто
   не было; systemd не поднял его сам, деплой это не заметил. Просроченное напоминание при
   старте молча сняли.
2. Обзор проактивности смотрит только личный чат: погодное напоминание живёт в беседе
   `-5290894512`, и для обзора «своих пунктов нет» — отсюда «обзор пуст».
3. Все задачи из моста отфильтрованы: `/v1/activity` не отдаёт владельца и область, поэтому
   P1-фильтр их безопасно скрывает — но полезных уведомлений по задачам нет.

## Что меняется
Домены `core`, `integrations`, `workflow`: автоперезапуск и внешний сторож бота, проверка
зелёного старта при деплое, доставка просроченного с пометкой, обзор по всем доступным чатам
пользователя, передача `userId`/`scopeId` задачи из агента в мост.

## Чего не делаем
Не меняем модель прав и правила P1; не включаем уведомления по задачам без подтверждённого
владельца (неизвестный — не общедоступный).

## Как проверяем
Бот поднимается после падения и после деплоя; при остановке его замечает внешний сторож и
пишет в чат; просроченное напоминание приходит с «пропущено, было на …»; обзор содержит пункты
из беседы; задача с владельцем из моста доставляется только владельцу.
