# Техническое решение

## Решение
В `src/tools/sendto-tool.mjs` при неудаче точного поиска добавить второй проход: сравнение по
первым трём буквам и по общему префиксу без учёта окончания. Возвращается только единственный
кандидат; при двух и более — прежний отказ с уточнением. Тексты ошибок не меняются.

## Альтернативы
Хранить список прозвищ у контакта — сложнее и требует участия владельца.
