# PLB-031: приёмка в release-артефакте и устойчивый тест статистики

Основание: deploy-safe блокировался двумя тестами, не связанными с фичей:
- acceptance tool не мог определить SHA без .git в release-каталоге;
- тест статистики падал на границе суток из-за несогласованного пояса.

## Что меняется
- acceptance tool читает BUILD_SHA/RELEASE_SHA, если .git отсутствует.
- упаковка release добавляет RELEASE_SHA.
- тест статистики пишет usage в тот же пояс, что читает API.
