# Техническое решение

## Решение
`sendVoice` по схеме `docs.getMessagesUploadServer` (type=`audio_message`) → загрузка OGG →
`docs.save` → `messages.send` с вложением. Сбой загрузки — текстовый откат, чтобы ответ не
потерялся. Зависит от PLB-010 (тот же файл адаптера), поэтому делается после него.

## Альтернативы
Отправлять файлом вместо голосового — хуже для пользователя, VK умеет audio_message.
