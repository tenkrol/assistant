# Изменение: единый контракт инструментов модели

## Зачем
Инструменты модели размазаны: часть в `*-tool.mjs`, часть внутри `bot.mjs` (sendto,
поиск по истории), часть внутри доменных модулей (опросы). Определение схемы, выполнение
и формат ответа у всех свои, поэтому новый инструмент добавляется правкой ядра, а тесты
приходится писать через фейковую платформу.

## Что меняется
Домен `tools`: единый контракт (схема, выполнение, результат), реестр инструментов в одном
месте, инструменты вынесены в `src/tools/`. Ядро получает список из реестра.

## Чего не делаем
Не меняем сами возможности и тексты ответов. Не трогаем домены и подключения.

## Как проверяем
785+ тестов зелёные; все инструменты доступны модели; добавление нового инструмента —
новый модуль + строка в реестре, без правок ядра.
