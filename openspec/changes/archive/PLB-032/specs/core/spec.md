# Дельта для домена core

## ADDED Requirements

### Requirement: Старые интервальные повторы от пяти минут остаются совместимыми
Словарь и вычисление следующего срока ДОЛЖНЫ принимать `every:N` для значений от 5
до 1440 минут с шагом 5. Создание нового напоминания МОЖЕТ применять более строгий
минимум в 15 минут.

#### Scenario: Сохранённый повтор каждые пять минут
- GIVEN в хранилище уже есть напоминание с повтором `every:5`
- WHEN запись загружается и вычисляется следующий срок
- THEN запись не отбрасывается
- AND следующий срок наступает через пять минут.
