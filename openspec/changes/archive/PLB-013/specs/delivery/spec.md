# Дельта для домена delivery

## ADDED Requirements

### Requirement: Единственный путь разметки
В проекте ДОЛЖЕН остаться один путь к разметке и стримингу — `src/delivery/`.

#### Scenario: Импорт после удаления шима
- GIVEN код нуждается в форматировании
- WHEN он импортирует модуль
- THEN путь ведёт в `src/delivery/`
- AND `src/format.mjs` отсутствует

#### Scenario: Поведение не изменилось
- GIVEN тесты форматирования и разбиения
- WHEN они запускаются после перевода импортов
- THEN все проходят
- AND выводимый текст тот же
