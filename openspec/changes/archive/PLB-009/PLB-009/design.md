# Техническое решение

## Как устроено сейчас
`/export` в `src/core/commands.mjs` собирает markdown-текст и отдаёт его файлом. PDF-рендер
есть в `src/tools/file-tool.mjs` и `src/pdf.mjs` (встроенный шрифт, перенос строк, страницы).

## Предлагаемое решение
Разобрать у команды необязательный аргумент формата (`/export pdf`). Для `pdf` собрать те же
разделы блоками (заголовок, абзацы, списки) и отдать через PDF-рендер, затем отправить
существующим `sendFile`. Для остальных значений — прежний путь без изменений.

## Влияние
Риск: разошедшееся содержимое выгрузок. Поэтому разделы строятся из одного источника данных,
а тест сравнивает, что в PDF присутствуют те же заголовки. Откат — `deploy-safe`.

## Альтернативы
- Всегда PDF: ломает привычный текст и тесты.
- Отдельная команда `/export_pdf`: лишняя сущность, формат уже параметр.
