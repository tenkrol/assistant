# Дельта для домена storage

## ADDED Requirements

### Requirement: Журнал обработанных событий агента
Хранилище ДОЛЖНО вести журнал `eventId` обработанных событий с атомарной записью, сроком
хранения и компакцией. Запись ДОЛЖНА появляться только после успешной доставки, чтобы сбой
не «съел» повтор.

#### Scenario: Повтор после рестарта
- GIVEN событие уже доставлено и записано
- WHEN сервис перезапускается и агент повторяет событие
- THEN журнал находит `eventId`
- AND повтор не доставляется

#### Scenario: Сбой до записи
- GIVEN доставка не удалась
- WHEN агент повторяет событие
- THEN `eventId` не считается обработанным
- AND доставка выполняется заново

### Requirement: Ожидающие вопросы агента
Хранилище ДОЛЖНО сохранять ожидающие вопросы агента по чату (задача, вопрос, время) и
восстанавливать их после перезапуска; просроченные вопросы снимаются.

#### Scenario: Рестарт с вопросом
- GIVEN агент ждёт ответа владельца
- WHEN сервис перезапускается
- THEN вопрос остаётся ожидающим
- AND ответ владельца продолжает ту же задачу
