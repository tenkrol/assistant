# Дельта для домена delivery

## ADDED Requirements

### Requirement: Результат агента доставляется в исходный чат
Текст результата агента ДОЛЖЕН оформляться с заголовком «Ответ агента», обрезаться по
лимиту площадки и отправляться в чат из маршрута результата, а не в первый попавшийся чат.

#### Scenario: Обычный результат
- GIVEN агент прислал результат
- WHEN бот его доставляет
- THEN сообщение приходит в исходный разговор
- AND длинный текст обрезан с пометкой

#### Scenario: Файлы результата
- GIVEN в событии есть файлы
- WHEN бот доставляет результат
- THEN сначала идёт текст, затем файлы документами/фото
- AND ошибка одного файла не отменяет остальные

### Requirement: Вопрос агента оформляется как вопрос
Вопрос агента ДОЛЖЕН доставляться отдельным сообщением с подсказкой, что ответить можно
обычным сообщением; служебные события (предложение памяти) через доставку не проходят.

#### Scenario: Вопрос
- GIVEN агент ждёт ответа
- WHEN вопрос доставляется
- THEN в тексте видно, что это вопрос по задаче
- AND служебное предложение памяти пользователю не показывается
