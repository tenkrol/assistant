# Техническое решение

## Как устроено сейчас
`src/bot.mjs` — один класс: приём сообщения, контекст, команды, возможности, тихие часы,
форматирование, стриминг, разбиение на части.

## Предлагаемое решение
- `src/core/conversation.mjs` — конвейер обработки сообщения.
- `src/core/commands.mjs` — маршрутизатор команд `/...`.
- `src/core/capabilities.mjs` — подсказка «что ты умеешь».
- `src/delivery/format.mjs`, `src/delivery/stream.mjs` — разметка, стриминг, разбиение.
- `bot.mjs` — фасад: собирает части, публичные методы остаются прежними.

Порядок: сначала вынести доставку (её тесты просты), потом команды, потом конвейер, фасадом
закрывать в конце. После каждого шага полный прогон тестов.

## Влияние
Риск: разъехавшиеся тексты и порядок шагов. Поэтому перенос дословный, а тесты поведения
остаются. Откат — `deploy-safe`.

## Альтернативы
- Оставить монолит: любая правка ядра требует понимания 1800 строк.
- Полный редизайн с новыми абстракциями: отвергнуто, риск для продакшена без выигрыша.
