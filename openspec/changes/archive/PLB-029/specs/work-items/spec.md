# Дельта для домена work-items

## ADDED Requirements

### Requirement: Запись дела
Модель ДОЛЖНА хранить цели, проекты, обязательства, решения, вопросы и результаты с
владельцем, областью доступа, источником, датами, статусом и историей; факт,
предположение и предложение различаются.

#### Scenario: Предположение
- GIVEN запись создаётся как assumption
- WHEN её читают
- THEN epistemic=assumption, а не fact.

#### Scenario: История
- GIVEN запись active
- WHEN статус меняется на done
- THEN в history есть переход и время.
