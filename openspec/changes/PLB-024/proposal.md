# PLB-024 — приглашения с принятием (P2-2 ревью)

## Зачем
Ревью 18.10: `invite` сразу добавляет активного участника, а отдельного шага «принято
получателем» нет — нарушение BP-03 («приглашение связывается с подтверждённой учётной записью
и принимается получателем»; ссылка/пересылка карточки доступа не даёт). Также нельзя смешивать
одноимённые числовые id разных платформ без подтверждённого связывания.

## Что меняется
Домен `core`: приглашение становится сущностью со статусом `pending`, TTL, кодом и принятием
получателем. До принятия `canRead`/`canWrite` не срабатывают. Отзыв — у владельца.

## Чего не делаем
Не меняем модель ролей и права чтения/записи (это PLB-018/PLB-022); не связываем аккаунты
платформ автоматически.

## Как проверяем
Приглашённый до принятия не видит данных проекта; после принятия видит; просроченное и
отозванное приглашение не даёт доступа; одинаковый числовой id на разных платформах не даёт
доступа к чужому проекту.
