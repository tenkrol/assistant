# Проект «Ассистент TenKrol»

Домашний ассистент для двух человек: чат-бот в Telegram и VK (напоминания, календарь,
память, дайджест, фото/документы/голос, файлы на выход, отправка сообщений другим), агент
для длинных задач и мини-приложение внутри Telegram.

## Репозитории
- `tenkrol/assistant` — бот и мини-приложение (этот репозиторий).
- `tenkrol/agent` — агент; у него свой `openspec/`.

## Стек и ограничения
Node.js 22 на серверах (24 локально), **ноль npm-зависимостей в рантайме**. Состояние —
JSON-файлы с атомарной записью. systemd, nginx, Let's Encrypt. Модель — DeepSeek через
OpenAI-совместимый API. Деплой — `tg-agent/tools/deploy-safe.mjs` с проверкой и откатом.

## Серверы
- **Испания** `185.174.136.53` — бот, сайт `tenkrol.ru`, мини-приложение и **xray/VPN (не трогать)**.
- **Финляндия** `185.106.94.155` — агент, сторож, зашифрованные бэкапы.

## Домены
`core` (разговор), `domain` (правила предметной области), `storage` (хранение), `integrations`
(внешние подключения), `tools` (инструменты модели), `config` (настройки), `agent-link`
(связь с агентом), `delivery` (доставка ответов), `miniapp`, `ops` (эксплуатация), `workflow`
(сам процесс разработки).

## Порядок чтения для новой сессии
1. этот файл;
2. `openspec/conventions.md`;
3. `openspec/specs/<домен>/spec.md` по нужному домену;
4. активные `openspec/changes/*` — что в работе.
