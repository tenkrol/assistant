# Чат-бот ассистента

Telegram- и VK-бот для двух человек: напоминания, календарь, память, дайджест, работа
с фото, документами и голосом, файлы на выход, опросы, конспект видео, поиск по истории,
мини-приложение с панелью. Рядом живёт агент для длинных задач.

## Возможности

| Что | Как |
|---|---|
| Напоминания и календарь | «напомни завтра в 9 купить хлеб», «запиши стоматолога 15 октября»; список — `/reminders`, `/calendar` |
| Фото, документы, голос | пришлите файл или голосовое — разберу, перескажу, достану текст |
| Файлы на выход | «сделай PDF с отчётом» — PDF, Excel, Word, CSV приходят документом |
| Отправка другому человеку | «напиши Марии, что задержусь» — уходит с подписью «От Вячеслава: …»; по телефону — если человек делился контактом |
| Опросы, конспект, история | опросы с кнопками, пересказ YouTube, `/search` по прошлой переписке |
| Дайджест | каждый день в 8:00: погода, праздники, совет, события, напоминания |
| Мини-приложение | `/app` — панель с напоминаниями, календарём, памятью и статистикой |
| Агент | длинные задачи уходят агенту, результат приходит в этот же чат (`agent-notify`) |

## Устройство

```
src/                 код бота: ядро, инструменты, платформы, хранилища
public/app.html      мини-приложение (Telegram WebApp)
tools/               деплой, бэкап, профиль бота, сторож
deploy/              юниты systemd
test/                тесты: node --test --test-force-exit
docs/                планы и заметки (перевод приложения)
```

Бот работает на двух платформах одним ядром: `src/platforms/telegram.mjs` и `src/platforms/vk.mjs`.
Порт платформы описан в `src/platforms/port.mjs`. В VK нет файлов на выход и голосовых
ответов — возможности, которых у платформы нет, бот честно не обещает.

## Чего пока нет

- перевод мини-приложения (ветка `app-translation`, план в `docs/TRANSLATION.md`);
- отправка файлов и голосовых ответов в VK;
- написать первым тому, кто не начинал диалог, — запрет Telegram, не бота.

## Запуск и проверка

```sh
node src/index.mjs                      # запуск (нужен .env, образец — .env.example)
node --test --test-force-exit           # все тесты
node tools/deploy-safe.mjs --notify     # безопасный деплой с откатом
node tools/backup-state.mjs --send      # бэкап состояния в Telegram
```

Секреты лежат в `.env` и в репозиторий не попадают: см. `.gitignore` и `*.env.example`.
