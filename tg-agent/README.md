# Ассистент TenKrol

Домашний ассистент для двух человек: чат-бот в Telegram и VK, автономный агент для
длинных задач и мини-приложение внутри Telegram. Работает на двух серверах: бот — на
«Испании», агент — на «Финляндии».

## Что умеет бот

| Возможность | Как пользоваться |
|---|---|
| Напоминания | «напомни завтра в 9 купить хлеб»; список — `/reminders`, отмена — `/cancel <номер>` |
| Календарь и события | «запиши стоматолога 15 октября в 11:30», «покажи события»; список — `/calendar` |
| Память о человеке | «запомни, меня зовут …», город — `/city <город>`; показать — `/memory`, забыть — `/forget` |
| Утренний дайджест | каждый день в 8:00: погода, предупреждения, праздники (официальные, церковные, народные), совет для здоровья, события, напоминания, анекдот; сейчас — `/digest` |
| Фото, документы, голос | пришлите файл или голосовое: расшифрую, перескажу, достану текст (`/voice вкл` — отвечать голосом) |
| Файлы на выход | «сделай PDF с отчётом», Excel, Word, CSV — приходит документом (`file`: xlsx/docx/csv/md/txt/pdf) |
| Отправка другому человеку | «напиши Маше, что задержусь» — уходит с подписью «От Вячеслава: …»; телефон — если человек делился контактом |
| Опросы | «создай опрос, куда едем: лес, река, дача» — с кнопками и подсчётом голосов |
| Поиск по истории | `/search слово` или «что мы решали про ремонт?» |
| Конспект видео | пришлите ссылку на YouTube — вытащу субтитры и перескажу |
| Сервер | `/server` — диск, память, uptime, службы |
| Мини-приложение | `/app` — панель с напоминаниями, календарём, памятью и статистикой (только Telegram) |
| Статистика и прочее | `/stats`, `/new`, `/whoami`, `/character`, `/mood`, `/mode`, `/export`, `/help` |

## Связь с агентом

Длинные задачи бот передаёт агенту, а результаты возвращаются в тот же чат:

1. бот → агент: HTTP-мост (`agent-bridge`), агент живёт на другом сервере;
2. агент → бот: агент дублирует свой ответ в точку приёма бота (`OUTBOX_TOKEN`), точка
   слушает только `127.0.0.1:8788`, туннель `tg-outbox-tunnel.service` ведёт к ней с
   сервера агента;
3. сторож `agent-run-watch.timer` раз в минуту видит завершённую задачу в журнале и
   присылает короткий отчёт, даже если агент сам не отчитался.

## Платформы

Одно ядро, два адаптера: `src/platforms/telegram.mjs` и `src/platforms/vk.mjs`,
контракт — в `src/platforms/port.mjs`. В VK нет файлов на выход и голосовых ответов,
нет меню «/», а кнопки в беседах обрезаются по лимитам VK — бот об этом честно
говорит и не обещает того, чего платформа не умеет.

## Устройство

```
src/                 ядро бота, инструменты, платформы, хранилища состояния
public/app.html      мини-приложение (Telegram WebApp)
tools/               деплой с откатом, бэкап, описание бота, сторож
deploy/              юниты systemd
test/                тесты: node --test --test-force-exit
docs/                планы (например, перевод приложения)
```

Состояние — обычные JSON-файлы в `/var/lib/tg-agent` (напоминания, события, память,
история, usage, справочник контактов). Запись атомарная, файлы переживают перезапуск
и полный диск.

## Надёжность

- **Деплой**: `tools/deploy-safe.mjs` — проверка синтаксиса, полный прогон тестов,
  переключение симлинка, проверка после запуска и автоматический откат при неудаче.
- **Бэкапы**: состояние уходит в Telegram ежедневно; отдельно, по 01:00 МСК,
  зашифрованный архив состояния бота и агента уезжает в Яндекс.Диск (пароль — вне
  серверов).
- **Сторож диска**: часовой таймер чистит кэш apt и журнал, предупреждает при нехватке
  места.
- **Тесты**: 728 локально, полный прогон перед каждым деплоем.

## Запуск и проверка

```sh
node src/index.mjs                       # запуск (нужен .env, образец — .env.example)
node --test --test-force-exit            # все тесты
node tools/deploy-safe.mjs --notify      # безопасный деплой с откатом
node tools/backup-state.mjs --send       # бэкап состояния в Telegram
node tools/set-profile.mjs --apply       # описание бота и сообщества
```

Секреты лежат только в `.env` и в репозиторий не попадают: см. `.gitignore`
и `*.env.example`.
