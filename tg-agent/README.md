# Ассистент TenKrol — бот

Домашний ассистент для двух человек. Работает как чат-бот в **Telegram** и **VK**
(адаптеры VK Teams и MAX тоже готовы), плюс мини-приложение внутри Telegram.
Бот живёт на сервере «Испания»; длинные задачи выполняет агент на «Финляндии».

## Что умеет

| Возможность | Как пользоваться |
|---|---|
| **Напоминания** | «напомни завтра в 9 купить хлеб», повторы («каждый вторник»), отложить кнопкой; `/reminders`, `/cancel <номер>`; тихие часы по часовому поясу пользователя |
| **Календарь и события** | «запиши стоматолога 15 октября в 11:30», годовой повтор, напоминание за N минут; `/calendar` |
| **Память** | «запомни: …», «что ты помнишь»; у каждой записи источник, область, статус и срок; `/memory` (с пагинацией и фильтром проекта), `/memory correct`, `/memory undo`, `/memory why`, `/forget` с уточнением области. Удалённое не возвращается |
| **Проекты и права** | `/project new`, `/project use`, `/project list`, `/project invite`, `/project revoke`, `/project archive`; роли owner/editor/viewer, данные изолированы по пространствам |
| **Документы как источник** | пришлите PDF/DOCX/XLSX/TXT — бот извлечёт текст, найдёт по смыслу и ответит со ссылкой на документ, версию, страницу и точным фрагментом; версии, сравнение, каскадное удаление |
| **Файлы на выход** | «сделай PDF с отчётом», Excel, Word, CSV — в Telegram и VK |
| **Выгрузка** | `/export` — текст `.md`; `/export pdf` — документ со всеми разделами |
| **Проактивность** | утренний обзор в 09:00 (по настройке), не больше 3 инициативных сообщений в день, только существенное: перенос времени, препятствие, завершение или ошибка. Кнопки «открыть / выполнено / отложить / отключить тип», объяснение «почему это пришло» |
| **Опросы** | «создай опрос …» — один голос на человека, повторный заменяет, закрытый голосов не принимает |
| **Написать другому** | «напиши Марии, что задержусь» — по имени из справочника, ник или телефон; мягкое сопоставление имён; отправляет от вашего имени с подписью |
| **Агент** | «дай агенту задачу …» — длинная задача уходит на отдельный сервер, ответ и прогресс приходят в чат |
| **Мини-приложение** | `/app` — панель внутри Telegram: напоминания, события, память, расход токенов; русский и английский, выбор языка сохраняется |
| **Голос** | принимает голосовые и расшифровывает; с `/voice вкл` отвечает голосом (Telegram и VK, при сбое — текстом) |
| **История диалога** | `/search <запрос>` и инструмент поиска по прошлым разговорам |
| **Расход и статистика** | `/stats` — токены, `/digest` — сводка дня |
| **Состояние сервера** | `/server` — диск, память, сервисы |
| **Погода и внешнее** | погода с предупреждениями, web-поиск и чтение страниц, YouTube, праздники, анекдоты, умный дом (Home Assistant) |
| **Режимы и характер** | `/mode`, `/character`, `/mood` — тон ответов |
| **Служебное** | `/new` — очистить контекст, `/whoami` — кто я, `/model` — модель, `/help` |

## Команды

`/start` `/help` `/whoami` `/new` `/reminders` `/calendar` `/memory` `/forget` `/city`
`/mode` `/character` `/mood` `/voice` `/stats` `/digest` `/cancel` `/model` `/export`
`/app` `/search` `/server` `/project`

## Инструменты модели

`remind`, `remember`, `file`, `event`, `poll`, `youtube`, `server`, `sendto`, `find_history`,
`documents`, плюс поиск и чтение в web, погода, праздники, анекдоты, умный дом.
Инструменты ходят в сеть только через `src/integrations/`.

## Как устроено

```
src/integrations/   всё сетевое: Telegram, VK, VK Teams, MAX, модель, Яндекс-речь, погода,
                    YouTube, web, умный дом, анекдоты, праздники, мост агента
src/storage/        атомарная запись, один писатель, версии схемы и миграции
src/domain/         правила: профили и память, напоминания, события, опросы, повторы
src/tools/          инструменты модели: единый контракт + реестр
src/delivery/       разметка под платформу, стриминг, разбиение длинных ответов
src/core/           конвейер сообщения, маршрутизатор команд, права, проекты, проактивность
src/bot.mjs         фасад: сборка, жизненный цикл, доставка
```

## Запуск, тесты, деплой

```sh
node --test --test-force-exit      # полный прогон
node src/index.mjs                 # локальный запуск (нужен .env)
node tools/deploy-safe.mjs --notify --test-timeout 900000   # деплой с автооткатом
```

Секреты — только в `../secrets/prod.env.enc` (шифртекст), пароль вне репозитория.
Расшифровка: `bash tools/secrets.sh decrypt`. Имена ключей — `../secrets/keys.md`.
