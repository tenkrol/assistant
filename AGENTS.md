# Инструкция для AI-сессии

Этот файл читают все, кто работает с репозиторием: человек, агент, любой другой инструмент.

## Сначала прочитать
1. `openspec/project.md` — что за проект, серверы, домены, ограничения.
2. `openspec/conventions.md` — язык, тесты, коммиты, DoD, секреты, запреты.
3. `openspec/changes/*` — что уже в работе.
4. `docs/HANDOFF.md` — состояние на сейчас.

## Главное правило
**Код меняется только в рамках папки изменения** `openspec/changes/PLB-<номер>/` со спекой
и задачами. Сначала спека и одобрение владельца — потом код.

## Git: работа не закрыта без коммита и пуша
Каждая сессия и каждый инструмент ОБЯЗАНЫ закоммитить свою работу и отправить её в origin
(в свою ветку: `git push origin <ветка>`). Незакоммиченное изменение считается потерянным:
его не видят ни владелец, ни другие сессии, ни `git pull` на другой машине.

Порядок в конце работы (обязателен):
1. `bash tg-agent/tools/spec-check.sh` — структура изменений;
2. `node --test --test-force-exit` — тесты;
3. `git add -A && git commit -m "…причина изменения…"`;
4. `git push origin <ветка>`;
5. `bash tg-agent/tools/git-check.sh` — подтверждает, что дерево чистое и всё отправлено.

Проверка не пропускает незакоммиченные файлы и неотправленные коммиты. Единственное
исключение — `.DS_Store`. Если пуш невозможен (нет доступа к origin), сессия обязана прямо
сказать об этом владельцу, а не молча оставить изменения незакоммиченными.

## Обязанности
- Спеки и комментарии в коде — по-русски.
- Перед деплоем — полный локальный прогон: `node --test --test-force-exit`.
- Деплой только через `deploy-safe`, он сам откатит при провале.
- Обновить `docs/HANDOFF.md` в конце сессии.
- Закрыть изменение: влить дельту в `openspec/specs/`, перенести папку в `changes/archive/`.
- Закоммитить и запушить результат: `git add -A && git commit && git push origin <ветка>`,
  затем `bash tg-agent/tools/git-check.sh`.

## Секреты
Открытым текстом — нигде. `secrets/prod.env.enc` (шифртекст) + пароль вне репозитория.
Расшифровка: `bash tg-agent/tools/secrets.sh decrypt`. Имена ключей — в `secrets/keys.md`.

## Запреты
- Не трогать xray/VPN на Испании.
- Не перезагружать серверы без явного разрешения владельца.
- Не менять `tg-agent/src/bot.mjs` без локального прогона тестов.
- Не хранить значения секретов в репозитории, в чате и в логах.
