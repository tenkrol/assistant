# Ассистент TenKrol

Домашний ассистент для двух человек: чат-бот в Telegram и VK, автономный агент для
задач с файлами и кодом, и мини-приложение внутри Telegram.

## Ветки

| Ветка | Что внутри |
|---|---|
| `chat-bot` | Чат-бот: напоминания, календарь, память, дайджест, голос, документы, файлы на выход, опросы, конспект видео, поиск по истории, мини-приложение |
| `agent` | Агент: длинные задачи, работа с файлами и кодом, мост к чат-боту, свой бэкап и сторож |
| `app-translation` | Перевод мини-приложения (первая задача) |
