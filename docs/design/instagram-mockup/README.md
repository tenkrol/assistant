# tenkrol — Instagram-style concept

Макет главного экрана и основных разделов в визуальной логике Instagram:
светлая тема, нижняя навигация, сторис, лента, исследование, Reels-поток и профиль-портфолио.

## Файлы

- `index.html` — интерактивный макет (4 телефона, чистый HTML/CSS без зависимостей).
- `mockup.png` — скриншот для быстрого просмотра и обсуждения.

## Экраны

| Экран | Что показывает | Роль в продукте |
|---|---|---|
| 01 · Лента | Сторис с быстрыми действиями, карточка «Сводка дня», результат агента | Главная: что произошло и что важно |
| 02 · Поиск | Поиск по чатам/файлам/памяти, сетка проектов и запросов | Исследование и навигация по контенту |
| 03 · Агент | Поток задач с прогрессом, статусами и повтором | Рабочий центр агента |
| 04 · Профиль | Статистика, био, highlights, сетка проектов | Личное пространство и портфолио |

## Маппинг на текущий сайт

- **Сторис** → быстрые действия: Сегодня, Сообщения, Планы, Файлы, Проекты, Ещё.
- **Лента** → дашборд + результаты агента + важные события.
- **Поиск** → глобальный поиск (пока раздельные поиски чата/файлов).
- **Reels** → лента задач агента; вертикальные карточки вместо списка.
- **Профиль** → память, статистика, проекты, настройки, achievements.
- **Плюс в центре** → создать: задача агенту, напоминание, заметка, фото.

## Что это меняет в UX

- Один главный экран вместо «Ещё из 20 плиток».
- Быстрые действия всегда наверху.
- Контент (результаты, заметки, события) выглядит как лента, а не как отчёты.
- Агент воспринимается как поток работы, а не как админ-панель.
- Профиль становится личным рабочим пространством.
