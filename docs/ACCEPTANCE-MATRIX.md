## Итог отчёта

`passed 26 · failed 0 · blocked 4 · skipped 0 · not-run 0` из 30 сценариев.
`blocked` — это ожидающие живой проверки сценарии, а не успех. Пересобрать:

```bash
node tg-agent/tools/acceptance.mjs --run --report
```

Отчёт фиксирует SHA базы и признак изменённого дерева. После коммита SHA изменится — отчёт и
матрицу нужно пересобрать на новом SHA, иначе доказательство относится к другой ревизии.
