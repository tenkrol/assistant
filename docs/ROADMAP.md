**ВЫПОЛНЕНО ПОЛНОСТЬЮ: PLB-008…PLB-014 задеплоены и заархивированы.** Бот работает на новой архитектуре.

## PLB-008 — перевод мини-приложения (следующая задача, спека уже в changes/PLB-008)

**Зачем:** панель внутри Telegram только на русском; нужен английский и основа для других языков.
**Домен:** `miniapp`.

1. Строки интерфейса — в словарях `public/locales/<язык>.json`, в разметке строк нет.
   - GIVEN панель открыта · WHEN язык английский · THEN все подписи на английском.
2. Одинаковый набор ключей во всех словарях; расхождение — ошибка теста.
3. Язык: выбор в `Telegram.WebApp.CloudStorage` (у каждого свой), по умолчанию — `language_code`
   из `initData`, если нет — русский.
4. Русская версия выглядит ровно как сейчас — это проверяется скриншотом и тестами.
5. Ошибки API мини-приложения приходят с кодом, клиент переводит их по словарю.

**Готово, когда:** русская версия не изменилась, английская переключается и сохраняется,
страниц без строк в разметке нет, тесты зелёные, задеплоено и проверено в Telegram.

## PLB-009 — PDF в `/export`

**Зачем:** `/export` отдаёт текст, а нужен документ; инструмент `file` PDF уже умеет.
**Домен:** `tools`.

1. `/export pdf` отдаёт PDF с теми же разделами, что текстовая выгрузка, кириллица корректна.
   - GIVEN есть память и напоминания · WHEN `/export pdf` · THEN приходит `.pdf` с теми же разделами.
2. Остальные форматы `/export` не меняются.
3. Ошибка сборки PDF — понятный текст, а не пустое сообщение.

**Готово, когда:** PDF приходит в Telegram, старые форматы работают, тесты зелёные.

## PLB-010 — файлы на выход в VK

**Зачем:** в VK инструмент `file` и `/export` отвечают «платформа не умеет», хотя VK умеет документы.
**Домен:** `integrations`.

1. Адаптер VK реализует `sendDocument` (загрузка через `docs.getMessagesUploadServer` → upload → `docs.save`).
   - GIVEN пользователь просит PDF в VK · WHEN файл собран · THEN он приходит документом в беседу.
2. Ошибка загрузки — понятный текст, а не тишина.
3. Список возможностей бота перестаёт обещать меньше, чем умеет VK.

**Готово, когда:** PDF, Excel и CSV приходят в VK, ошибки объясняются, тесты зелёные.

## PLB-011 — голосовые ответы в VK

**Зачем:** `/voice` в VK отвечает «недоступна»; VK поддерживает `audio_message`.
**Домен:** `integrations`.

1. Адаптер VK реализует `sendVoice` (upload type `audio_message` → `docs.save`).
   - GIVEN в VK включён `/voice вкл` · WHEN бот отвечает · THEN приходит голосовое.
2. Если VK не принял голосовое — ответ уходит текстом, без потери содержания.
3. Подсказка возможностей в VK говорит правду.

**Готово, когда:** голосовые приходят в VK, текстовый откат работает, тесты зелёные.

## PLB-012 — мягкое сопоставление имён в sendto

**Зачем:** в справочнике «Маша», а просят «напиши Марии» — сейчас честный отказ.
**Домен:** `tools`.

1. Совпадение по началу имени: «Мария» находит «Машу», если других кандидатов нет.
   - GIVEN в справочнике одна «Маша» · WHEN просят написать «Марии» · THEN сообщение уходит ей.
2. Если подходят двое и больше — не угадывать, а спросить, кого именно.
3. Неизвестное имя — перечислить, кто есть.

**Готово, когда:** «Мария» и «Маша» работают, неоднозначность не угадывается, тесты зелёные.
